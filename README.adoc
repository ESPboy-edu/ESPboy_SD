The SD library allows for reading from and writing to SD cards using ESPboy SD module.

### Connection:

* Battery VCC 3.80V → diode → 3.36V SD
* GND → GND SD
* SCK (GPIO14) → CLK SD
* MISO (GPIO12) → MISO SD
* MOSI (GPIO13) → MOSI SD
* B7 MCP23017 → CS SD
